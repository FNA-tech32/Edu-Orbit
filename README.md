# Edu Orbit

Edu Orbit is a static coaching website for people moving from feeling stuck to thriving. The site presents retreats, one-to-one coaching, and small-group sessions, plus the values and guides behind the work.

## Pages

- `index.html` — home page
- `privacy-policy.html` — how visitor information is collected and used
- `terms-of-service.html` — terms for coaching, retreats, and programs

## Home page sections

- **About** — who the coaching is for and how retreats and ongoing support fit together
- **Coaches** — Yvonne Padilla, Dr. Kim Bland, and community coordinator Angelina
- **The Journey** — awareness, breakthrough, integration, and flourishing
- **Our Offerings** — Discovery Map Retreat, Edu Orbit Coaching, and small group sessions
- **Values** — wholeness, honesty, partnership, and shared strength
- **Contact** — email, phone, studio address, and a message form

## Run locally

No install step is required. Open `index.html` in a browser, or serve the folder:

```sh
python -m http.server 8080
```

Then visit `http://localhost:8080`.
